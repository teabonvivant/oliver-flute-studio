停學多年再拿起長笛：讓身體慢慢記起來

張老師音樂學院 · 發表於 2026 / 09 / 22 · 2 分鐘

本文目錄

用現在的狀態安排起點留一首只是喜歡的曲相關學習方向

舊笛盒的扣子仍很熟悉，手指卻比記憶遲了一步。重新學長笛，不必由以前最難的作品證明自己。先確認樂器狀況，再用容易的聲音、熟悉的節奏，把身體的記憶一點點接回來。

擱置多年的長笛可能需要檢查按鍵與皮墊。如果某些音總是很難發出，不要立即認定自己退步太多。請老師或維修技師看看，能避免把樂器問題錯當作練習不足。

用現在的狀態安排起點

挑一首音域不闊、節奏清楚的短曲。先讀譜，再慢慢試奏，記下是看譜、指法還是氣息最容易打斷你。三項能力恢復的速度未必一樣，可以分開處理，不需要一次重拾所有技巧。

以較短時間開始，吹奏之間留休息。以前能維持的練習長度，未必適合現在的生活和身體狀態。舒服、穩定而能再次拿起樂器，比某一天練得特別久更有價值。

留一首只是喜歡的曲

除了基本練習，可以保留一首喜歡的小曲，不把它變成考核。選幾句最熟悉的旋律，留意它今天帶來甚麼感覺。音樂不只用來檢查失去了多少，也讓你想起當初為何願意開始。

每星期錄一小段，用相同樂句比較。你也許先找回的是拍子，然後才是音色，沒有必要與過去的級數逐日對照。重返學習的路可以從容；舊經驗仍在，只是需要一個合適的入口，讓它與現在的你重新相遇。

打開笛盒之後：把練習的首五分鐘留給聲音

笛盒打開，樂譜也放好了，手卻習慣直奔最難的一行。長笛的首五分鐘可以另有安排：先讓身體、樂器和耳朵一起進入狀態。這段時間不必追求音域寬廣，選幾個已經容易發聲的音，聽它們今天是否仍然從容。

樂譜上的一個逗號：替長笛樂句安排換氣

旋律吹到一半，氣快用完，眼睛才開始找地方停。換氣若總在最後一刻決定，樂句便容易像被剪斷的句子。較穩妥的方法，是先離開樂器，把旋律唱出來，再在譜上用鉛筆留下幾個有意思的逗號。

輕聲也要站得穩：長笛弱奏的起音練習

樂譜上寫着 p，聲音一放輕，第一個音卻不見了。長笛弱奏並不是把所有力量一起撤走。音量可以小，氣流的方向仍要清楚，舌頭放開後也要有聲音接住。與其勉強吹得極細，不如先找一個能重複做到的輕聲。
