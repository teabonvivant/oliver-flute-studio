# 切換 oliverflute.com 到新網站

狀態（2026-10-31）：未切換。正式網址仍是 Strikingly 舊站；GitHub Pages 是預覽。

## 切換前要 Oliver 確認

1. 舊站 13 個密碼頁（`drum-lesson1–8`、`drum-lesson61`、`mindruml1／2／5`、`2024mindrum`）的內容未搬，新站只有轉到空靈鼓課程頁。登入被 hCaptcha 擋住，要由 Oliver 在瀏覽器開頁取內容；舊站停用後就取不到。
2. 舊站 `2`、`3`、`5`、`6`、`12` 亦只有轉向，切換前再確認內容已不需要。
3. 主網域用 `www.oliverflute.com` 還是 `oliverflute.com`，以及網域註冊商／DNS 由誰管理。
4. E9（考級與比賽）立場、三篇舊文錯處（見 `_team_runs/notes-merge-20261031/待核實-處理結果.md`）。

## 步驟

1. `SITE_ORIGIN=https://www.oliverflute.com node build.mjs && SITE_ORIGIN=https://www.oliverflute.com node tools/verify_site.cjs`
2. 在 `dist/assets/` 加 `CNAME`（內容＝主網域），改 `tools/deploy-pages.sh` 帶同一個 `SITE_ORIGIN`，發布到 gh-pages。
3. GitHub → Pages → Custom domain 填主網域。
4. DNS：`www` CNAME 到 `teabonvivant.github.io`；裸網域 A 記錄指向 GitHub Pages 官方 IP（以 GitHub 文件當時所列為準）。
5. HTTPS 憑證發出後勾 Enforce HTTPS。
6. 實測：首頁、任何一篇文章、舊網址（如 `/abrsm`、`/aboutme`）、`/sitemap.xml`、WhatsApp 按鈕。
7. Google Search Console 驗證新站並提交 sitemap。舊站至少保留到新站確認正常才停用。

## 限制

GitHub Pages 不能做 301，舊網址用 meta refresh＋canonical。回滾＝DNS 指回 Strikingly。
