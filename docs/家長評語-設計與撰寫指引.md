# 家長評語：設計與撰寫指引

2026-11-14｜張老師音樂工作室（oliverflute.com）

網站已預留「家長和學員怎樣說」一節。現在資料檔是空的，所以網上看不到；收到真實評語、填入 `content/testimonials.json` 後重新建置，就會出現在：

- 課程總覽頁、家長指南頁：顯示最多 3 則
- 四個課程頁：只顯示該課程的評語（`page` 填課程頁檔名）

位置在每頁「課程常見問題」之下、WhatsApp 查詢按鈕之上——讀者看完資料、準備決定的時候，剛好看到別的家長怎樣說。

## 一、為甚麼要有評語

家長揀老師，最想知道三件事：小朋友喜不喜歡上堂、有沒有進步、老師好不好溝通。網站上的資歷和相片說明「老師是誰」，評語補上「跟這位老師學是怎樣的」。這一點，老師自己寫多少都代替不了。

## 二、一則好評語的樣子

每則 40–90 字，講一件具體的事。好評語通常有這三部分（不必齊全）：

1. **開始前的情況**：例如「女兒最初吹不出聲，有點想放棄」
2. **一個具體改變**：例如「第三個月開始自己拿長笛出來練」「考完五級」「在學校音樂會獨奏」
3. **對老師的一句觀察**：例如「張老師會講清楚回家練哪一句，我這個不懂音樂的家長也跟得上」

要避免的寫法：

- 只有形容詞：「老師好好、好有耐性、推薦！」——讀者讀完記不住
- 誇大或保證：「一定考到」「最好的老師」
- 太長：超過 120 字，網站上會變成一大段，反而沒人讀完

**格式示範（以下是寫法示範，不是真實評語，不可放上網站）：**

> 「兒子九歲開始學長笛，最初只吹得到兩三個音。張老師每堂都會寫低回家練哪一句、練多久，我照住提他就得。半年後他自己會揀曲吹給嫲嫲聽。」
> ——陳太｜長笛學生家長｜2024 年起

> 「退休後想學點新東西，以為自己手指不靈活。空靈鼓初班第一課已經敲到一首短歌，八課後同班同學一起合奏，好有滿足感。」
> ——Mandy｜空靈鼓入門初班學員

## 三、怎樣向家長收集

不要叫家長「寫一段評語」——大部分人不知道寫甚麼。改用三條問題，家長用 WhatsApp 文字或語音回覆都可以，再由你整理成一段：

1. 小朋友（或你自己）開始學之前，是怎樣的？
2. 學了之後，有沒有一件事令你印象深刻？
3. 你會怎樣向朋友形容張老師的課？

整理時只刪口頭語和重複，**不改意思、不加內容**。整理好後，把最終文字傳回家長確認，並問清楚署名方式。

可以直接用的 WhatsApp 訊息：

> 「X 太你好，我正在整理網站，想放幾段家長分享，讓新家長了解上堂是怎樣的。方便的話，可以用幾句話（文字或語音都得）答三條問題嗎？
> 1）開始學之前，小朋友是怎樣的？
> 2）學了之後，有沒有一件事令你印象深刻？
> 3）你會怎樣向朋友形容這個課？
> 我整理好會先給你看，你同意先會放上網站，署名用『陳太』或你喜歡的稱呼都可以。多謝！」

## 四、同意與私隱

- 每則評語都要有本人同意放上網站，留存 WhatsApp 對話作紀錄
- 署名只用稱呼（陳太、Mandy、小明媽媽），不放全名、學校或相片，除非對方明確同意
- 小朋友本人的評語，要家長同意
- 學員要求刪除，24 小時內從資料檔移除並重新發布

## 五、填入網站

`content/testimonials.json` 的 `items` 加一項：

```json
{
  "quote": "評語正文（不用加引號，網站會自動加「」）",
  "name": "陳太",
  "relation": "長笛學生家長",
  "course": "",
  "since": "2024 年起",
  "page": "flute-course.html",
  "approved": true
}
```

- `page` 留空＝放在課程總覽頁及家長指南頁；填課程頁檔名＝只在該頁出現
- `approved` 要是 `true` 才會上網站；未確認的可以先填 `false` 存着
- 之後執行 `node tools/render-site.mjs`、`node build.mjs`，再發布
- 如建置提示「字型未收錄」（評語有網站未用過的字，例如「嫲」），按 README「中文字型」重跑 `tools/build_fonts.py`，否則該字會用後備字體顯示
- 設計截圖（示範文字）：本機 `_team_runs/clarity-20261114/m-voices.png`、`d-voices.png`

## 六、建議數量

先收 6–9 則：長笛、笛子／洞簫、空靈鼓各 2–3 則，最好兒童家長和成人學員都有。之後每學期補一兩則，保持新鮮。

## 七、搜尋結構資料

暫時**不加** Review／AggregateRating 星級結構資料。Google 不會為「自己網站上評自己」的商戶評語顯示星級，加了也沒有效果，還可能被視為不當標記。評語在網站上的作用是讓讀者信任；搜尋上的評分，留待日後 Google 商家檔案收集真實評價。
