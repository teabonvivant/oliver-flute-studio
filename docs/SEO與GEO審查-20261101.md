- 跳轉頁已改為：絕對網址 canonical（指向新頁，不含 #）、移除 noindex、meta refresh 0 秒。
- GitHub Pages 做不到 HTTP 301。Google 把 0 秒 meta refresh 當轉向處理，但傳遞速度與可靠度不及 301。**建議正式上線時 DNS 放 Cloudflare（免費），用 `dist/assets/_redirects` 內 254 條規則（Bulk Redirects／Pages）做真 301。**
- 舊站主機是 `www.oliverflute.com`（裸網域 301 到 www），所以新站主網域也要用 www，canonical／sitemap 才不會改變。
- 新增頁面（練習室工具、topic-*、drum-accessories 等）直接以新網址收錄在 sitemap，不需轉向。
