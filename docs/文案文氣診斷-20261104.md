# 全站文案文氣診斷（2026-11-04）

範圍：`content/notes/` 68 篇音樂手記（82,641 字）＋ 61 個頁面。舊站 20 篇手記原文不動。

## 一、判斷：現在的文筆偏向哪一邊

偏向**產品說明書**，不是散文。

句子正確、資訊準確、沒有明顯 AI 套話（早前已清過一輪），但整站有一個共同的聲音問題：**沒有人在說話**。像一份寫得很好的使用須知——每一句都對，讀完記不住任何一個人。

| 指標 | 全站現況 | 問題在哪 |
|---|---|---|
| 有「我」的篇數 | 12 / 68（56 篇一次都沒有） | 老師不在場，只剩制度在講話 |
| 平均句長 | 23.4 字 | 合格，但分布太窄 |
| 段落平均句數 | 2.0 | 每段兩句，全部一樣長，讀起來像條列 |
| 長句（40 字以上）佔比 | 6% | 沒有可以「沉下去」的句子 |
| 小標題用問句 | 182 / 264（69%） | 26 篇全部問句，像 SEO 目錄 |
| 成語 | 幾乎為零 | 中文的壓縮與重量全部流失 |
| 每篇「可以」 | 6.5 次 | 萬能動詞，判斷被磨平 |

## 二、五個系統性問題

**1. 無主語通告體。** 「先不用吹。」「選一個容易的中音。」「錄三次相同的短句。」連續十幾個祈使句，主語省掉，語氣就變成廣播。中文散文不會這樣走，因為讀者聽不見是誰在給建議。

**2. 段落碎成兩句。** 為了手機閱讀把每段切成兩句，結果全篇節奏一致，沒有一處可以慢下來。小思寫一件小事，往往一段四、五句，中間一句長句把時間拉開。

**3. 小標題全是問句。** 「譜架也會改變聲音？」「弱奏的起音為甚麼會消失？」同一句式重複幾十次。問句本身沒有問題，問題是**只有**問句。

**4. 沒有聲音。** 談音色、談笛膜、談餘音的文章，全篇沒有一句把聲音寫出來。這是音樂文章最不該缺的東西。

**5. 收尾一律喊一句。** 「下次練習，揀一個音，只聽它的音頭、音中或收音其中一處。」每篇用同一個句式收，讀三篇就發現是模板。

## 三、已完成的改動（三篇樣本）

改寫範圍：`flute-tone`（技巧）、`parents-before-start`（家長）、`dizi-learning-hk`（本地／成人／兒童）。三篇的結構、錨點、圖片位置、FAQ、內部連結全部保留。

**開場：由判斷改成現場**

| 前 | 後 |
|---|---|
| 長笛音色要由一個音的三段來練：怎樣開始、中間氣流是否持續、怎樣結束。 | 有學生吹完一句，把笛橫在膝上，先問一句：是不是這支笛不夠好？ |
| 孩子第一次上音樂課，不必先背好音名，也不用急着買齊用品。 | 第一堂前一晚，家長通常在 WhatsApp 問同一件事：要買定樂器嗎？ |
| 在香港學笛子，兒童的興趣和基本功不必二選一…… | 孩子吹不響，把笛放下，說不想學了。 |

**小標題：由目錄改成句子**

| 前 | 後 |
|---|---|
| 譜架也會改變聲音？ | 譜架挪一寸，聲音也跟着變 |
| 弱奏的起音為甚麼會消失？ | 弱奏不是把氣收細 |
| 最後一個音不要急着放 | 末音是一句話的句號 |
| 買第一件樂器，先試甚麼？ | 揀樂器，先試手，不必先試牌子 |
| 一對一課堂應該包含甚麼？ | 一對一課堂，應該有這四樣 |

**術語：英文在前，中文在括號**

`p（piano，弱奏）`、`staccato（斷奏）`、`legato（連奏）`。首次出現加註，同篇後文不再重複。

**成語：少而貼題**——按圖索驥（照抄照片）、欲速不達（同一句指令越說越大聲）、一曝十寒（練得久不如練得密）、大興土木（為練習角改裝家居）。

**語氣：建議，不是指令**——「我通常會請學生」「不必急」「我不會說每個人都一樣快」。

## 五、建議的推行次序

每批 6 至 8 篇，同一批內混三種題材（技巧／家長／樂器文化），避免同一句式在相鄰文章重複。次序按流量與轉換價值排：

1. 入門三組：`flute-first-flute`、`flute-daily-practice`、`dizi-first-dizi`、`drum-start`、`practice-time`
2. 考級組：`exam-roadmap`、`exam-pieces`、`exam-mock-and-nerves`、`exam-video`
3. 家長組：`parents-daily`、`parents-performance`、`flute-choose-teacher`
4. 文化與聆聽：`listening-live`、`listening-how`、`dizi-schools`、`dizi-vs-xiao`
5. 其餘技巧篇

主頁面（首頁、關於、四個課程頁、家長頁）另案處理：那些是 HTML 內的文案，改動要連版面一起看，不在這批之內。
